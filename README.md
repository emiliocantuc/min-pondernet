### min-pondernet

A single-file reproduction of [PonderNet](https://arxiv.org/abs/2107.05407) trained on the parity task described in Sec 3.1 of the paper.


### Usage
```bash
# clone repo or download main.py
uv run main.py
# or just
uv run https://raw.githubusercontent.com/emiliocantuc/min-pondernet/refs/heads/main/main.py
```
